# Security and privacy notice

This repository contains a static demonstration app. It is not designed or approved for real patient data.

- Do not enter names, national identifiers, contact details, medical record numbers, or identifiable health information.
- Entries are stored in browser localStorage on the current device/browser. Anyone with access to that browser profile may be able to view them.
- No authentication, encryption-at-rest control, server-side authorization, audit trail, or secure multi-user storage is implemented in this static demo.
- Do not treat GitHub Pages as a patient-data hosting environment.
- For a real deployment, complete a privacy impact assessment and security review, implement appropriate technical and organizational safeguards, and obtain institutional/legal review.

Report a repository security issue privately to the repository owner; do not post sensitive information in public issues.
